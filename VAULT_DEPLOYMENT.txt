Issue: "Login failed" or "Request failed"
Solution: Check browser console for errors. Verify:
  • Backend is running
  • /api/auth/login endpoint exists
  • CORS is configured (if vault is on different domain)

Issue: "Session expired" after refresh
Solution:
  • Check /api/auth/me endpoint
  • Verify session token is stored in localStorage
  • Check token expiry in backend

Issue: Data doesn't persist after refresh
Solution:
  • Open browser console → Application → Local Storage
  • Check for "vault_session_token"
  • Verify /api/vault GET returns data
  • Check vault_data table in database

Issue: Discord login doesn't work
Solution:
  • Verify DISCORD_CLIENT_ID and DISCORD_CLIENT_SECRET are set
  • Check redirect URI is configured in Discord developer portal
  • Verify /api/auth/discord-oauth/start endpoint exists

Issue: CORS errors
Solution:
  • Vault HTML must be served from same domain as backend
  • If testing locally, use http://localhost:3000/vault.html
  • Don't use file:// protocol for production testing

Issue: Migration fails with "relation already exists"
Solution: Table already created, this is OK. Check:
  railway run psql -c "\d vault_data"
